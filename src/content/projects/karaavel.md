## Collaboration d'ingénierie logicielle

Au sein de l'écosystème Karaavel, l'objectif consistait à bâtir une colonne vertébrale numérique capable d'alimenter simultanément une application de gestion web professionnelle et une application mobile réactive.

## Responsabilités techniques

- **Backend API robuste** : Modélisation des données relationnelles complexes sous Django ORM, endpoints sécurisés via tokens JWT, pagination et filtres optimisés.
- **Frontend professionnel** : Intégration d'écrans de pilotage clairs avec React et Flutter, gestion des états asynchrones et synchronisation des données.
- **Conteneurisation Docker** : Déploiement reproductible garantissant la parité exacte entre environnement de développement local et serveurs distants.
